# 🌱 Seedling Survival Analysis

## 📌 Project Overview

This project analyzes seedling survival and mortality data from
dryland tree-growing and restoration activities in Kenya.

The analysis focuses on understanding seedling survival patterns
across different seasons and monitoring sites and generating
evidence that can support improved tree establishment and
restoration interventions.

## 🎯 Objectives

- Assess seedling survival and mortality rates.
- Compare survival patterns across monitoring periods.
- Identify variations in seedling establishment.
- Visualize survival and mortality trends.
- Apply statistical methods to support interpretation of the data.
- Generate evidence to inform future seedling establishment and
  monitoring activities.

## 📊 Key Indicators

The analysis includes indicators such as:

- Number of seedlings planted
- Number of surviving seedlings
- Number of dead seedlings
- Survival rate (%)
- Mortality rate (%)
- Seasonal differences
- Site-level differences where applicable

## 🔬 Analytical Approach

The analysis follows a structured data-analysis workflow:

1. Data import and validation
2. Data cleaning and preparation
3. Descriptive statistics
4. Calculation of survival and mortality rates
5. Exploratory data analysis
6. Data visualization
7. Statistical testing where appropriate
8. Interpretation of findings
9. Recommendations

## 📈 Analysis Outputs

The project produces:

- Seedling survival rates
- Seedling mortality rates
- Seasonal comparisons
- Tables and summary statistics
- Data visualizations
- Statistical analysis results
